Slide template syntax

{{name}}Insert a value. {{client.address.city}} walks nested data.
{{{name}}} / {{&name}}Insert without HTML escaping (raw).
{{name | filter}}Apply filters, chain with |: upper, lower, title, capitalize, trim, length, default:x, number, money, currency:€, date:%B %d, %Y, join:, , sum:amount, json, raw.
{{#if field}}...{{else}}...{{/if}}Conditional section. Empty / zero / false values are skipped. {{#unless field}} inverts.
{{#each items}}...{{/each}}Repeat over a list. Inside: {{this}}, {{@index}}, {{@number}}, {{@first}}, {{@last}}, {{@length}}.
{{! hidden comment }}Comment - not rendered.

Slides & layouts

Insert slide offers four layouts that change how a slide looks when presented:

  • Title - large centered heading + subtitle.
  • Content - regular slide with a heading and body.
  • Section - dark divider slide for new chapters.
  • Exercise - content slide primed with fill-in-the-blank placeholders.
  • Blank - an empty canvas.

Drag slides on the strip to reorder, use the ... menu to rename, duplicate, move or delete, and press Present to run the deck fullscreen (arrow keys, F fullscreen, Esc to exit).

Fill-in preview: toggle Fill in on the Preview tab to type values straight into the slide - every {{variable}} becomes an underlined blank, computed values (filters) are read-only, and + Add item / - Last manage each {{#each}} list. Great for classroom exercises.

Tip: dates work best as ISO strings (2026-08-05) - use the date filter to format them.
